Each theme uses its base color for the toolbar, active tab and new-tab page. The window frame, address bar and incognito windows use darker shades of the same color. Text and icons are white.

## Install

1. Download or clone this repo.
2. Open `chrome://extensions` (or `brave://extensions`).
3. Turn on **Developer mode** (top-right).
4. Click **Load unpacked** and select one theme folder, e.g. `green-themes/forest-green-014421`.

To remove a theme: **Settings → Appearance → Reset to default**.
